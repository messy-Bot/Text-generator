# Text Generator with Font Styles

## Overview

**Text Generator with Font Styles** is a Python desktop application built using the **Tkinter** GUI framework. The application allows users to enter custom text, preview it in a selected font style, and instantly copy the formatted text to the system clipboard. It provides an intuitive interface with a large collection of font options, making it useful for experimenting with typography and creating visually appealing text.

The application includes an extensive list of over **200 font styles**, enabling users to quickly compare different fonts without needing separate text editing software. The simple interface makes it suitable for beginners as well as users looking for a lightweight font preview tool.

## Features

* User-friendly graphical interface built with Tkinter.
* Enter custom text through an input field.
* Select from 200+ font styles using a dropdown menu.
* Instantly preview the text in the selected font.
* Copy the generated text directly to the system clipboard.
* Displays confirmation after successful copy operation.
* Lightweight and easy to run with Python.

## Technologies Used

* Python 3
* Tkinter (GUI Library)

## How It Works

1. Launch the application.
2. Enter the desired text in the input box.
3. Select a font style from the dropdown list.
4. Click **Generate Text** to display the text in the selected font.
5. Click **Copy Text** to copy the displayed text to the clipboard for use in other applications.
